# Sepolia evidence (ERC-8471, revision 4)

The evidence run of `script/SepoliaEvidence.s.sol` was executed a second time on Sepolia (chain id 11155111) with the revision-4 contracts, on 2026-10-29 between 20:34:24 and 21:16:12 UTC, blocks 12021936 to 12022145: the ADRF kernel (the policy registry, the six modules and the dispute registry), the three methods, the bridge over the live ERC-8436 registry, the revised worked-example escrow bound to a fast-track policy, and the two complete flows — a double charge, now filed as a claim about the second settlement under the proposition the escrow recognizes for it, verified on chain and refunded from the held settlement; and a delivery-quality claim judged by an ERC-8436 roster and refunded from the held charge — with real transactions. 45 transactions, all successful, 132,369,646 gas, 0.002109 ETH in fees. The files of the record are `deployments/sepolia-rev4.json` (addresses and identifiers), `deployments/sepolia-rev4.transactions.json` (every transaction with hash, block, status, gas used and effective gas price) and this document; `scripts/sepolia-readback.sh` reads the state below back from the chain and `scripts/sepolia-verify.sh` submits the contracts to Sourcify (both default to this record). The revision-3 run of the same day (46 transactions, blocks 12017706 to 12017916) is recorded in `docs/sepolia-evidence.md` with `deployments/sepolia.json`; its contracts stay deployed and are not touched by this run.

## Execution

Foundry 1.7.1 (forge, cast), solc 0.8.30, via-IR, optimizer runs 200, EVM cancun — the settings of `foundry.toml`, so the contracts on chain are the ones `forge build` produces from this repository at revision 4. The run was driven by `scripts/sepolia-run.sh all` with `RECORD` at its default `sepolia-rev4`: the pre-flight (chain id, balance, the live ERC-8436 registry, the six largest creations estimated by the node against the 16,777,216-gas per-transaction cap — `ADRFServiceEscrow` 14,675,960 or 87%, `ADRFFilingModule` 13,902,360 or 82%, `ADRFPolicyRegistry` 13,520,604, `ADRFDecisionModule` 13,512,296, `ADRFResolutionModule` 11,217,263, `ADRFOutcomeModule` 9,298,322), then the seven phases with `forge script --broadcast --skip-simulation --gas-estimate-multiplier 150 --slow --code-size-limit 65536`, waiting eleven minutes where a window had to lapse, then the record, which took the newest seven run files of the broadcast directory (the revision-3 run's seven files are still there). Every gas limit came from the node's `eth_estimateGas`; each transaction was confirmed before the next was sent; the script deploys from the compiled artifacts (`vm.deployCode`).

One thing differs from the revision-3 run by design. The ERC-8436 fast-track policy the script registers is content-addressed and its specification is the same as in revision 3 (same family, derived from the chain id and the deployer; same derived jurors; same windows), so the live ERC-8436 policy registry already held it and refused a second registration (`ACDF: policy exists`; a first attempt of the deploy phase stopped there during local execution, before any transaction was sent). The script now computes the policy identifier, finds the policy registered and reuses it — `0x328b3d82…`, the policy the revision-3 run registered — which is why this run has 45 transactions where revision 3 had 46. The attestor panel is registered again on the new `AttestorQuorumRule` and, being derived from the same three attestors with the same quorum, has the same identifier as in revision 3.

Sepolia's gas schedule as measured by this run: creation cost between 1,570 and 1,777 gas per byte of deployed code (the escrow at 14,559,471 gas, 87% of the cap, as the pre-flight had estimated to within 1%; the nine units whose bytecode is unchanged from revision 3 cost exactly the gas they cost then), a plain transfer to a funded account 21,000 gas, `file` 3.56 million gas, `openJudgment` 2.41 million, `importResult` 1.41 million, `finalize` of the dispute registry 0.87 to 1.30 million, `enact` 0.60 million. The base fee was 15 to 16 wei throughout; the effective gas prices (0.01 gwei for the deploy and formal-file phases, 0.125 and 0.1 gwei for the two phases after the first wait, 0.03 and 0.001 gwei afterwards) are the priority fees the node suggested to Foundry at the time, and they make up nearly all of the 0.002109 ETH in fees.
